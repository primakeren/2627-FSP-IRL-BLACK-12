# CV Template — Grey/White Professional

This folder contains a simple, elegant CV template (HTML + CSS) derived from the provided PDF layout. The design is intentionally:

- Dominantly white with black accents
- Clean, professional and print-friendly
- Responsive — works in desktop and mobile

Files added:

- cv-template/index.html — the CV page you can open in a browser
- cv-template/style.css  — styles

How to use

- Offline: Download the files and open `index.html` in any modern browser.
- Online: Host the `cv-template/` folder on any static site hosting (GitHub Pages, Netlify, Vercel).
- Print/PDF: Use the browser Print dialog (Ctrl/Cmd+P) to export to PDF — the template includes a print-friendly style.

Customization

- Edit the contact, profile, education, and other sections directly in `index.html`.
- Change colors in `style.css` (CSS variables at the top) to tune the palette.
